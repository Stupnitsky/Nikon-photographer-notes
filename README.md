# Nikon photographer notes

Фан-страницы о технике Nikon. Проект неофициальный и с компанией Nikon не связан.

## Страницы

| Файл | Что на странице |
| --- | --- |
| `index.html` | **Объективы NIKKOR Z**: таблица 49 объективов с фильтрами и сортировкой, цены Nikon USA на 10 сентября 2026 года, даты выхода. |
| `straps.html` | **Ремни репортёров Nikon**: какие ремни носили фоторепортёры с 1950-х до Z9, рейтинг, эпохи, артикулы заводских ремней, фотографии и источники. |

## Устройство

Обычный статический сайт, сборка не нужна.

```
index.html          страница объективов
straps.html         страница о ремнях
assets/menu.css     стили общего меню
assets/menu.js      поведение меню: открытие, тёмное стекло над тёмными блоками, растровая кромка
img/straps/         фотографии для страницы о ремнях
CREDITS.md          авторы и лицензии фотографий
CLAUDE.md           заметки проекта для работы через Claude
.nojekyll           GitHub Pages отдаёт файлы как есть
```

Шрифты (Figtree и Onest) подключаются с Google Fonts.

## Как посмотреть

- На компьютере: открыть `index.html` в браузере.
- В интернете: включить GitHub Pages (Settings → Pages → ветка `main`, папка `/`). Адрес будет `https://stupnitsky.github.io/Nikon-photographer-notes/`.

## Фотографии

Все фотографии взяты под свободными лицензиями или из общественного достояния. Авторы и лицензии перечислены в [CREDITS.md](CREDITS.md) и в подписях на странице. Две фотографии разрешены только для некоммерческого использования, поэтому рекламу на сайте размещать нельзя.
